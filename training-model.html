Adaptive Marathon Training Model

On-demand coaching logic with effort feedback integration

Core Principle: The model generates one workout at a time, never a future schedule. Each recommendation is computed fresh from current training state. Post-run effort ratings feed back into distance, intensity, and recovery calculations.

4. Adaptive Progression Engine

Long Run Progression

next_long = min(current_long + Δ, 34km)
Δ = 1.5km × effort_multiplier × consistency_factor

Effort multiplier

Effort 1-41.2
Effort 5-61.0
Effort 7-80.5
Effort 9-100.0 (hold)

Consistency factor (28-day)

Runs/wk: 1.5 → 0.8 penalty

Weekly Volume Adaptation

target_weekly = max(12km, recent_4wk_avg × (1 + effort_trend/20))
effort_trend = Σ(last_4_effort_ratings) / 4

If average effort > 7.5 for 2+ consecutive weeks, volume plateaus regardless of schedule.

5. Recovery Intelligence

Auto-Recovery Triggers

Effort 9-10 yesterday
Two 8+ efforts in 3 days
Long run +24h, effort 7+
3+ consecutive run days

Recovery Run Formula

distance = max(3km, recent_avg × 0.4)
max(20min, comfortable pace)

Recovery never exceeds 40% of recent average run distance. Minimum 3km to maintain rhythm.

6. Marathon Readiness Estimation

Comfort (7/10 effort) readiness requires hitting both weekly volume and long run thresholds.

Effort Level Weekly km Long run km Est. Timeline
10/10 Struggle 42 28 ~8 weeks
9/10 Hard 48 30 ~10 weeks
8/10 Strong 54 32 ~12 weeks
7/10 Comfort 60 34 ~14 weeks
weeks_to_ready = max(
  (target_weekly - current_weekly) / 3,
  (target_long - current_long) / 1.5
)

7. Real Adaptation Example

Week 1: 3km @ effort 3 → +20% → 4km
Week 2: 4km @ effort 4 → +15% → 5km
Week 3: 5km @ effort 7 → hold → 5km
Week 4: 5km @ effort 8 → -10% → 4.5km + rest
Week 5: 4.5km @ effort 5 → resume → 6km

The model backpedals on volume when effort spikes, preventing overtraining. Progression resumes when sustainable effort returns.
