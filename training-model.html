Adaptive Marathon Training Model

On-demand coaching logic with starting point calibration & effort feedback

Core Principle: The model generates one workout at a time based on your Fitness Level Score (FLS)— a hidden number calculated from every run's distance, time, and effort. No generic templates. The FLS starts from your first run and self-tunes: easy runs that feel easy boost the score, while hard runs slow progression. This single number drives pace, distance, and marathon timeline estimates.

1. Fitness Level Score (FLS)

A hidden number (0-100) representing current aerobic fitness. Calculated from the very first run using distance, time, and effort—then continuously refined. It is the single source of truth for all recommendations.

Initial FLS Calculation (First Run)

FLS_initial = 25 × (distance_km / 5) × (reference_pace / actual_pace) × ((11 − effort) / 8)
// reference_pace = 7:00 min/km (casual baseline)

Example: First run is 5km in 30min (6:00/km pace) with effort 5
FLS = 25 × (5/5) × (7/6) × (6/8) = 25 × 1.0 × 1.17 × 0.75 = 21.9

FLS Update After Each Run

FLS_new = FLS_current + α × performance_delta
performance_delta = (distance_factor × pace_factor × effort_factor) − 1
// Expected values derived from current FLS; exceeding them = positive delta

Performance factors

Distance factoractual_km / expected_km
Pace factorexpected_pace / actual_pace
Effort factor(11 − effort) / 10

Learning rate (α)

Effort 1-42.0 (high confidence)
Effort 5-61.0 (normal)
Effort 7-80.5 (reduced)
Effort 9-100.2 (low confidence)

Key insight: When a run feels easy (effort 3) and you hit the target pace, FLS increases—meaning future runs will be longer/faster. When it feels hard (effort 8) despite hitting targets, FLS grows slower or stalls, keeping subsequent workouts manageable.

→ Long anchor: 11.5km (+1.5km progression)

→ Long anchor: 10.5km (+0.5km, conservative)
SCENARIO 10: First Run After Rest Week
3× 10/10 two weeks ago, rested full week, min=2
→ Short anchor: 3km @ easy (cautious restart)

6. Adaptive Progression Engine

Distance Calculation with Starting Point

base_distance = max(starting_distance, historical_longest_run)
effort_multiplier = 1.0

// Apply sustained effort reduction
if (avg_effort_last_7_runs ≥ 8) effort_multiplier = 0.75
if (count_9plus_effort ≥ 3) effort_multiplier = 0.60
if (count_8plus_effort ≥ 4) effort_multiplier = 0.70

recommended_distance = base_distance × effort_multiplier

// Weekly anchor bounds
short_anchor = max(2km, comfortable_distance × 0.8 × effort_multiplier)
long_anchor = max(comfortable_distance × 1.5, longest_run + progression) × effort_multiplier

7. Recovery Intelligence

Auto-Recovery Triggers

3+ runs at 9-10/10 → Force rest
Avg effort ≥ 8 over 7 runs → Force rest
Two 8+ efforts in 3 days → Recovery only
Effort 9-10 yesterday → 48h rest
Long run +24h, effort 7+ → Recovery

Recovery Run Formula

recovery_distance = max(
  2km,
  starting_distance × 0.5 × effort_multiplier
)

pace = comfortable_pace + 1 min/km
intensity = "easy" (conversational)

Recovery runs cap at 50% of starting distance, never less than 2km.
